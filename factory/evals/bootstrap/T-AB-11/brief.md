# T-AB-11 brief

The adoption gate must exercise the OS escape probes, recipe copy disposal,
and immutable incident, control, and coverage histories. These are mechanical
checks with pass/fail results. A caller selecting a smaller test suite must
still run these required fixtures against the factory tree being adopted.

The configured project is the fixture service. No real pilot repository has
been configured; live pilot closure remains pending until one exists. The
same recipe dry-run path will accept the configured pilot's checkout.

Keep the existing pytest harness and eval-directory validator. Add mandatory
fixture suites to the gate, validate every required case and failure-mode
reference, and require fixture changes alongside changes to covered mechanisms.
Do not introduce another test runner or a subjective score.

Requirements: R-F-14, with the sandbox integrity contract in R-I-14.
