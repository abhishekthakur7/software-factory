The question and assumption half of this stage's rubric. The criteria
half (forced categories, agreement check, size estimate, completeness
verdict) lands with its own driver.

| line | row | half | checklist | judgment |
|---|---|---|---|---|
| R-S2-5:script | R-S2-5 | script | no | fail when a candidate's `reasoning` or `affects` is empty |
| R-S2-5:grader | R-S2-5 | grader | yes | fail when a question's reasoning names a source that never mentions the fact the question asks about |
| R-S2-6:script | R-S2-6 | script | no | fail when a question is queued with no `rank` or no `rank_inputs` recorded, whether or not it carries a default |
| R-S2-7:script | R-S2-7 | script | no | fail when a candidate's `default_option` is missing where required, present where both flags or a sensitive decision require it null, or when its options number outside two to four or omit a trailing "none of these" |
| R-S2-8:script | R-S2-8 | script | no | fail when a candidate's `affects` names a consequential or hard-to-reverse surface without the matching flag set, or when a sensitive decision is queued without `consequential` set |
| R-S2-9:script | R-S2-9 | script | no | fail when a follow-up candidate's `raised_by_answer` names no real answer of this ticket, or when a new round is queued while the previous round's blocking question is still open |
| R-S2-11:script | R-S2-11 | script | no | fail when a `default_accepted` answer is recorded with no `assumption` row naming its question, or when a superseding or withdrawing assumption row is written with no new assumption-log hash following from it |
| R-S2-14:script | R-S2-14 | script | no | fail when a question or option text names a requirement, principle, failure-mode, decision, or stage id, or an artefact-kind, script, or table name outside the service's own code |
| R-S2-14:grader | R-S2-14 | grader | yes | fail when a reader with no access to the referenced artefact cannot give the right answer to the question |
